# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

This project is in pre-alpha stage. Security fixes will be applied to the latest `main` branch and released as patch versions.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public GitHub issue.
2. Email **security@paulenko.dev** with a description of the vulnerability and, if possible, a proof of concept.
3. Include the affected version and any relevant configuration details.
4. You will receive an acknowledgment within 48 hours.

## Disclosure Timeline

- **T+0**: You report the vulnerability privately.
- **T+48h**: We acknowledge receipt and begin investigation.
- **T+7d**: We provide an initial assessment and estimated fix timeline.
- **T+30d**: We publish a fix and coordinate public disclosure with you.

## Scope

This policy applies to the `behave-modern-sheets-report` package and its source code. Vulnerabilities in third-party dependencies (e.g., `openpyxl`, `odfpy`, `behave`) should be reported to their respective maintainers.
